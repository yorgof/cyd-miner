Install cyd-miner

Firmware for the Freenove FNK0103L "Cheap Yellow Display": live Bitcoin stats and a solo miner. See the project page for what it does.

  1. Connect the board to this computer with a USB cable that carries data.
  2. Click Install and choose the board's serial port, which is usually named after its CH340 chip.
  3. When it has finished, the board's screen names a WiFi network. Join it with a phone and fill in the page that opens: your WiFi, a pool and a Bitcoin address.

This browser cannot reach serial ports. Use Chrome or Edge on a computer, or download cyd-miner-…-factory.bin from the releases page and write it with esptool.py write_flash 0x0 cyd-miner-…-factory.bin.

Installing needs this page to be opened over HTTPS.

Installing replaces the firmware that is on the board and any cyd-miner settings saved on it. To update a board that already runs cyd-miner and keep its settings, upload the -ota.bin file on the miner's own web page instead.
